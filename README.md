# Make the AI Judge Laugh: Cat Reviews Its Human

A one-star review written by a house cat about its human: a deadpan complaint about an ungrateful human who screamed at the mouse it was gifted, ending with the cat going on strike from contributing to the household.

## Entry

> One star. I brought him a mouse and he screamed. Ungrateful. I have since stopped contributing to this household.

## How it works

`main.py` writes the single-line review above to `/output/entry.txt`. No network, no randomness — the same text every run.
